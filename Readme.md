## Damit die Seite erscheint

GitHub zeigt eine Organisations-Profilseite nur, wenn zwei Bedingungen erfüllt
sind — beides ist noch offen:

1. **Repository in `.github` umbenennen** (*Settings → General → Repository name*).
   Aktuell heißt es `Beck-Heun-GmbH`. Ein Repository mit dem Namen der
   Organisation wird von GitHub nicht als Profil-Repository erkannt; das gilt
   nur für persönliche Konten.
2. **Repository öffentlich stellen** (*Settings → General → Danger Zone*).
   Solange es privat ist, bleibt die Profilseite unsichtbar. Damit wird auch die
   Historie dauerhaft öffentlich — enthalten sind nur die Web-Logos und der
   Text der Profilseite.

Danach ist die Seite unter <https://github.com/Beck-Heun-GmbH> zu sehen.
